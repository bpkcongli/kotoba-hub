## Findings and resolution

1. **High: semantic collision in the proposed six-item runtime activation.**
   Provisional `/items/5/localizations/en/meaningOptions/distractors/18` was
   `pen`, alongside the correct `ballpoint pen`. Independently inspected
   mapped ペン (JMdict 1121380) means pen, so this is also a reasonable English
   translation of ボールペン. Exact normalized alias filtering does not catch
   this parent/child meaning relationship. Resolved for this integration by
   excluding item `506c5576-24cf-5e3f-ae16-77826bf0c8d1` from both promotion
   and the new Indonesian overlay. The item's existing pending English pool
   retains this known limitation; no fix or readiness is claimed for it.

2. **Medium: existing 切手 English answers combined unrelated senses.**
   `/items/[id=4cf91acd-62fa-52d3-8b05-e540af15b45d]/answerOptionPayload/canonicalAnswers/ENGLISH`
   included sense-2 `merchandise certificate`; the package selects sense-1
   postage stamp/prangko. The explicit reviewed correction removes only that
   alias, preserving `stamp (postage)` and `postage stamp`. Applied with global
   content/translation revisions 2/2. Raw source and pending registry remain
   unchanged. This was a baseline defect exposed by curation.

3. **Five-member runtime copy must describe five members.**
   The unpublished curation intentionally proposes six, including a ballpoint
   pen. The final runtime manifest keeps suitable equivalent titles and
   descriptions listing exactly the accepted five. This condition is resolved.
   The new group uses revision 1 and current en/id translation revision 1;
   these revisions are separate from the existing global flashcard overlay.
